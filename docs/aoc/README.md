## 🎯 What is AOC?

The Agent Operations Center (AOC) is your mission control for deployed AI agents and digital twins. It provides:

- **Real-Time Control** - Start, pause, stop agents on demand
- **Live Monitoring** - Stream activity logs as they happen
- **Performance Metrics** - Track success rates, latency, and throughput
- **Team Collaboration** - See who's viewing and recent changes
- **Command Palette** - Quick actions via keyboard shortcuts (⌘K)
- **Workflow Visualization** - Interactive graph of agent workflows
- **Audit Trail** - Complete history of all changes
- **Advanced Search** - Find anything across logs and runs
