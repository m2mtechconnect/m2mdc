# Accessibility results

- One `h1` per page ("Connections & Data Exchange", "Platform readiness"); heading order is logical.
- Tabs are keyboard reachable and operable; focus rings visible on all interactive controls.
- Status is conveyed by icon plus text label, never by colour alone.
- Health-check results announce through an `aria-live` polite region.
- Every disabled action carries a visible explanation (`DisabledActionExplanation`).
- Label text is at least 12px; essential targets are at least 24x24px.
- No horizontal document overflow at any tested viewport; no console errors observed.
