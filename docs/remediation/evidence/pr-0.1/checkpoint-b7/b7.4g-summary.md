### 2. Route boundary hardening (`src/App.tsx`)

Approved-user surface now exposes exactly two mount points:
`/pilot/*` (PilotShell) and `/sign-out`. Every other path
redirects to `/pilot/overview`, so blocked legacy routes
(`/dashboard`, `/builder`, `/operations`, …) cannot mount
`AuthenticatedShell` at runtime.

### 3. Pilot redirect fix (`src/pilot/PilotShell.tsx`)

Runtime verification of scenario S9 (unknown pilot subpath) exposed
a real defect: the unknown-route `<Navigate to="overview" replace/>`
was **relative**, so under the `/pilot/*` splat it concatenated
`overview` to the current URL, producing a runaway redirect chain
(`/pilot/x/overview/overview/overview/…`). Fixed by making the
redirect absolute (`to="/pilot/overview"`). Verified: S9 now lands
on `/pilot/overview` in one hop.

### 4. Shared denied-state a11y (`src/pages/PendingApproval.tsx`)

Axe flagged `landmark-one-main` and `region` on the PendingApproval
screen shown for unapproved authenticated users. Wrapped in a
`<main>` landmark and labelled the info card as a `region`.
Zero violations post-fix.
