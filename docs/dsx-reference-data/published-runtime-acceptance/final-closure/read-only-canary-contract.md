# Read-only canary contract

The administrator canary is now named **NVIDIA DSX Reference - Read-only**
(hyphen per the project typography rule; no em dashes).

Supporting text rendered in the banner and the registry descriptor states:
official-source normalized reference data, administrator-only canary, read-only,
not operational telemetry, not commissioned, not an NVIDIA DSX runtime service,
not SimReady validation, NGC-dependent fields remain unavailable, production
default unchanged.

The label flows to every surface that renders `descriptor.label`: the canary
banner, the reference surface header, the unavailable surface, the dataset
registry page, KPI strips and the evidence drawer.

Montreal remains a separate descriptor: AURA-authored, derived, simulated, not
commissioned, not connected, eight inputs Not supplied, no NVIDIA attribution.
The four reference facilities were not renamed or merged.
