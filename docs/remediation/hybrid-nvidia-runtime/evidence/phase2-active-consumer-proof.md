# Phase 2 evidence - active consumer proof

Generated by repository scan (`rg`) at Phase 2 closure. Reproduce with:

```
rg -l "simulationOrchestrator" src --glob '!src/simulation/orchestrator/**'
rg -l "BuilderPreviewEngine|MockSimulationEngine|generateSimulationResult|compat/sovereignDataCenterEngine" src tests cypress
```

## Modules that dispatch simulation execution

Every execution path in the application funnels through exactly one of these
four adapters, and each of them calls `simulationOrchestrator`:

| Module | Role | Downstream consumers |
| --- | --- | --- |
| `src/simulation/api.ts` | Public simulation facade | Workspace, dashboard and evidence surfaces |
| `src/simulation/compat/facadeBridge.ts` | Legacy sovereign shim (`runSovereignScenario`) | `src/twins/sovereignDataCenter/hooks/useSovereignDCTwin.ts` |
| `src/simulation/compat/previewSessionBridge.ts` | Builder preview sessions | `src/components/builder/step5/*` |
| `src/simulation/useSimulationCompletion.ts` | Run completion / persistence | Simulation workspace |

No other module constructs an engine or calls one directly.

## Remaining references to frozen engines (all accounted for)

| characterization / compat specs | Pin frozen behaviour; explicitly exempted |

## Constructions and legacy entry points removed in this pass

- `runSimulation` removed from the `twins/sovereignDataCenter` barrel, closing
  the last import surface through which application code could execute a
  sovereign scenario without provenance.

## Enforcement

- ESLint `no-restricted-imports` (`eslint.config.js`) - now scoped to `**/*.{ts,tsx}`
  (whole repository), with every exemption enumerated in `ignores`.
- `src/simulation/orchestrator/__tests__/bypassGuard.test.ts` - scans `src/`,
